Game pause stops every clock; game resume puts each button back as it was, so a button that was paused or uncaptured stays that way. While game-paused a button can't be captured; a 6 s hold on it takes it out of the game pause into a regular pause. Commands go to each button over its own connection, so they land within a fraction of a second of each other. To copy settings, use "Copy to all" in a button's settings.
