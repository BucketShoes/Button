Game pause stops every clock; game resume puts each button back as it was, so a button that was paused or uncaptured stays that way. While game-paused a button can't be captured; a 6 s hold on it takes it out of the game pause into a regular pause. Commands go out once and the buttons pass them on to each other, so they reach buttons you aren't connected to as well. To copy settings, use "Copy to all" in a button's settings.
